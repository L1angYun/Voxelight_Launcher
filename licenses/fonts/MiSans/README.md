Official source: https://hyperos.mi.com/font/zh/download
Downloaded archive: https://hyperos.mi.com/font-download/MiSans.zip
Retrieved: 2026-10-27

The application embeds the original, unmodified WOFF2 files. No subsetting,
conversion or alteration was performed. MiSans is credited in Settings → About.
The Windows installer also carries MiSans Regular and Semibold TTF files, which
it loads privately for its own pages and does not install on the system.
