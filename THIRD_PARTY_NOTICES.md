`licenses/dependency-inventory.json` records the locked npm and Cargo package versions, declared licenses, evidence sources, notice types and collected notices. `licenses/npm/` and `licenses/cargo/` contain the actual license, copying and notice files when those packages or their pinned upstream sources provide them. This includes transitive and target-specific dependencies in the lockfiles, not just the direct dependencies listed above.

Some target-specific npm packages have no separate notice in their own package. Entries marked `optional-parent-notice` reuse the real text from a parent explicitly related by `optionalDependencies`, only after checking the exact same version, registry name/version/integrity, repository and license declarations. The entry's `source` identifies that parent and relationship; the reuse is not inferred merely from a shared package name or organization. The `resolved-parent-notice` entries for the winapi target crates similarly record their exact Cargo resolve relationship to `winapi@0.3.9`.

A small number of upstreams provide a license declaration but no standalone license notice in the package or verifiable upstream tree. Entries marked `upstream-declaration-and-spdx-license-text` preserve the actual `Cargo.toml.orig` or registry `package.json` together with the canonical `licenseText` returned by the official SPDX JSON endpoint after checking `licenseId`. These are **upstream declarations plus official standard license texts**, not representations that the upstream package contained an original LICENSE file. Original OR declarations are preserved, including alternative terms; choosing a compatible option does not remove the other declared choices. File-level MPL-2.0 terms remain applicable to the corresponding third-party files.

The installer is generated by Tauri's bundler and the separately distributed NSIS toolchain. Those build-time tools and their plugins retain their own licenses; relevant collected notices are included under `licenses/`.

## Project artwork and character resources

The geometric application icon and `WorldScene` SVG artwork are original project resources under GPL-3.0-only. No Aceternity source component, paid UI template, third-party launcher wallpaper or copied launcher branding is included.

**Steve and Alex remain available as user-selectable default characters.** Their complete texture files are not bundled as GPL project artwork. Only after the user selects one does the launcher read the corresponding PNG from the Minecraft client JAR, using the official v2 version manifest and the official client download's expected size and SHA-1. The image is returned to the running interface, not redistributed in the source archive. These game textures and the Minecraft name belong to their respective owners. This is a technical compatibility mechanism, not a claim that Mojang has relicensed its textures under GPLv3.

## Design references

The Lens, Lattice and Overture-inspired interaction language was designed after studying [ruiqichenbiec/design-systems](https://github.com/ruiqichenbiec/design-systems), an MIT-licensed project (Copyright (c) 2026 DayDreamInAReverie). Its documentation and demonstrations informed the shared spring state, point-set selection frames and progress, and aperture, develop and spring timing used in `src/visual/`. No source file, shader, stylesheet, font, image or sound from that repository is included. The Voxelight implementation is original GPL-3.0-only work; published numeric tuning values (spring stiffness, damping and timing presets) are used as parameters. If any of that project's material is ever copied into this one, its MIT copyright and permission notice must be added here and shipped under `licenses/`.
