# Voxelight 0.6.0 审查修复清单

- 日期：2026-11-03
- 基线：`main` @ `287a3af`（历史改写前为 `feat/frontend-transitions` @ `f08cb9c`，文件内容相同）
- 依据：用 `d5e31ad`（改写前 `9d3b641`）时同一套测试数据和采集脚本重新采集画面，前后对比；4 路独立审查，39 条发现经复核保留 34 条
- 上级文档：`2026-11-03-voxelight-frontend-transitions-and-surfaces.md`（以下称“转场方案”）

## 结论

转场生硬已基本解决：切页、开卡和返回、分区切换、弹窗都有了中间帧，透镜不再冲过目标，身份块连续飞行。

但世界被调得过重，带来三个打开就能看到的观感回归：首页右下被实体柱铺满，内容页背景满屏白点，导航透镜把这些白点折射成彩色条纹。另有几处真实缺陷。下面按优先级分组，A 组必须先做。

转场方案第 4.2、4.3 节的部分数值本身有问题：遮罩只有 160px 渐隐，世界系数只约束了首页岛面。下面的修正以本文为准，并写回转场方案。

## A 组：世界观感（必须修，同批验收）

### A1 首页右下实体柱过重

- **现象：** `x ≥ 380, y ≥ 440` 区域的世界像素覆盖率，深色 1280 从 4.7% 升到 51.1%，深色 1050 从 4.8% 升到 63.9%，浅色 1280 从 27.4% 升到 80.7%。浅色下几乎是一面灰墙。
- **原因：** `shaders.ts:234` 渐隐带的柱深最多 9 格，俯角下侧壁大面积露出；`shaders.ts:239` 用 `1.1 * uLat * isl` 照亮了岛核外整条 18 格的渐隐带（转场方案为 0.55）。
- **修法（只改 `shaders.ts`，不回退 `horizon.at.y = 11`）：**
  1. `:234` 改为 `depth = mix(s, 3., m * mix(1., crE * crE * crE, uLat))`，柱深上限约 3 格；或让渐隐带里宽度不足 0.5 格的柱子直接不画。
  2. `:239` 改为 `vLit = max(vLit, 1.1 * uLat * smoothstep(uIsland + 6., uIsland, d))`，满光只给岛核。
  3. 仍偏重时：渐隐带从 `+18` 收到 `+10`，或首页 `preset.island` 从 9 降到 6。
  4. 可选：`:256` 的反照率下限乘以从顶点传出的岛权重。
  5. 以上都不够时，才把 `at.y` 调到约 13，并重新校准 `.vx-home__feet`。

### A2 内容页白点“雪”

- **现象：** 点的 alpha 约为改动前的 3.2 倍（`.42 + 1.47` 对 `.13 + .62`），尺寸下限提到 1.05，高处再放大 45%。深色是加法混合，饱和成纯白。标题带亮点占比从 0% 升到 2.0–3.7%，导航条区域均值从 13.4–15.1 升到 18.1–20.9。
- **修法：**
  1. `worldDirector` 的 `sceneValues` 新增标量 `pointGain`（内容页 0.3，首页 1）和 `home`（内容页 0，首页 1），加入 `scalarKeys`，随切页插值；不要用 `frame.page` 做 0/1 开关，否则切页会跳变。
  2. 以 uniform 传入。`shaders.ts:192` 的 alpha 乘 `uPointGain`，再 `alpha = min(alpha, .85)`。
  3. 尺寸下限改为 `mix(.72, 1.05, uHome)`，高度增益 1.5 和 1.45 都乘 `uHome`。

### A3 导航透镜里的彩色条纹

- **原因：** 主要是 A2 的高亮点场；导航条背景透明，色散 0.65 把每个白点拆成三色。
- **修法：**
  1. 先修 A2，再复看。
  2. 仍有残留时，给内容页世界画布加顶部渐隐：在 `WorldScene` 根节点新增 `data-world-page`（目前没有这个属性），内容页时设 `mask-image: linear-gradient(to bottom, transparent 0, #000 150px)`；或在点片元中按屏幕 y 做同样的衰减。
  3. 还不够时，才给 `.vx-floating-nav__indicator` 局部设 `--vx-lens-dispersion: .2`。不要做“静止时降色散”的切换，因为缓存键含色散值，切换会重算贴图。
- 运动中“←”出现重影属于正常折射，不用处理。

### A4 首页遮罩在 x≈360 处的硬切线

- **原因：** `home.css:13-15` 在 96% 实色平台之后只用 160px 线性降到 0，360 处一阶导数突变，形成马赫带。这是转场方案原文的数值。
- **修法：** 宽度改为 `calc(max(40px, (100% - 1280px) / 2) + var(--home-rail) + 300px)`，背景改为缓动多段色标：

  ```css
  background: linear-gradient(90deg,
    var(--world-ink) 0,
    var(--world-ink) calc(100% - 320px),
    color-mix(in srgb, var(--world-ink) 88%, transparent) calc(100% - 250px),
    color-mix(in srgb, var(--world-ink) 62%, transparent) calc(100% - 180px),
    color-mix(in srgb, var(--world-ink) 32%, transparent) calc(100% - 110px),
    color-mix(in srgb, var(--world-ink) 10%, transparent) calc(100% - 45px),
    transparent);
  ```

- `--world-ink` 在浅色主题下按现有回退取 `--bg-base`。减少透明和高对比的实底（`home.css:257-258`）不变。标题不能落进渐隐区。

### A 组验收

先用同一方法测 `d5e31ad` 和 `287a3af` 的基线（改写前为 `9d3b641`、`f08cb9c`），确认与上面的数字可比；方法不同导致数值有出入时，说明差异并以相对变化为准。

| 指标 | 测量方法 | 目标 |
|---|---|---|
| 首页下半区覆盖率 | `still-*-home`，区域 `x ≥ 380, y ≥ 440`，与背景色亮度差超过 10/255 的像素占比 | 深色 ≤ 20%，浅色 ≤ 35% |
| 岛面均值 | 沿用 0.6.0 报告的岛面采样 | 100–150 / 255 |
| 远景 | 沿用 0.6.0 报告的远景采样 | p95 在 60–80 |
| 内容页标题带 | 深色内容页 `x 400–1000, y 90–180`，亮度超过 60 的像素 | < 0.5% |
| 导航条区域 | 深色内容页导航条区域均值 | ≤ 15 |
| 遮罩 | 浅色首页逐列取 `y 200–700` 的最小亮度 | 无拐点线 |
| 对比度 | `world-acceptance` 现有断言 | 全部通过 |
| 角色站位 | 1280×720、1050×720、1920×1080 | 脚落在岛上 |

把首页下半区覆盖率和内容页标题带两项加入 `world-acceptance`，作为长期指标。

## B 组：首页交互（必须修）

### B1 启动时标题跳动

- **现象：** 点“启动游戏”后，`.vx-home__identity` 一帧上跳约 105px，选择器却在滑（`LaunchConsole.tsx:72`），两者不同步。
- **修法：** `.vx-home__identity` 改为 `motion.div layout="position"`，`layoutDependency` 取启动状态，transition 与选择器相同；`tier !== "full"` 时不加 layout。`.vx-launch-console__status` 加 140ms opacity 入场，只淡非玻璃内容。不要改成常驻的进度槽，那会改变首页构图。

### B2 实例选择器盖住标题

- **现象：** 列表向上展开盖住 `h1`，玻璃把白色标题折射成污渍，左缘露出残字。
- **修法：** 选择器展开时给控制台设 `data-picker-open`，同时把 `.vx-home__identity` 设为 `opacity: 0`（80ms，减少动态下 0ms）。列表 `inset-inline-start: -4px`，完全盖过标题左缘。

### B3 首页整页淡入包住了玻璃控件

- **修法：** `motion.ts:56` 改为 `animated = !home && tier !== "none"`，首页 stage 的 opacity 恒为 1；改用 `vx-home-content-reveal` 只淡非玻璃块。

### B4 实例名和版本重复显示

- **修法：** 删掉 `HomePage.tsx:233-237` 元数据行中与选择器重复的版本和加载器，只留 Java 等补充信息；`aria-label` 保留实例名。

### B5 取消按钮不透明度跳变

- **现象：** 250ms 防误触结束时，“取消准备”的不透明度从 0.55 一帧跳到 1。
- **修法：** 给 `.vx-launch-console__launch-wrap .vx-button` 追加 `opacity var(--duration-fast) var(--ease-out)` 过渡，保留原生 `disabled`；Lite 和减少动态下 `transition: none`。

## C 组：缺陷（必须修）

### C1 探索页搜索失败后像卡死

- **现象：** 同一来源下“搜 A 成功、搜 B 失败”后，A 的结果以 inert 状态一直留着；重新提交同一查询时 `setSearch` 因值未变而不发请求。
- **修法：** `useDiscover.ts` 的 catch 在同代次时 `setResult({ key: contextKey, source, items: [] })`；提交同一查询时递增 retry nonce，并纳入请求 effect 的依赖。
- **测试：** 补用例：第一次成功、第二次失败后网格中没有卡片；再次提交同一查询会重新请求。

### C2 身份块飞行中钻到详情面板后面

- **原因：** `library.css:2068-2071` 的 opacity 动画让 `.vx-detail-layout` 形成层叠上下文，画在只有 transform 的身份块之上。
- **修法：** `.vx-detail-header { position: relative; z-index: 2 }`，`.vx-instance-identity[data-layout-id] { position: relative; z-index: 3 }`。先核对两者在同一层叠上下文。返回路径上，飞行期间给目标卡片设 `position: relative; z-index: 2`。
- **测试：** `transitions.spec` 逐帧用 `document.elementFromPoint` 取身份块中心，断言命中身份块本身。

### C3 浅色主题选中项看不出来

- **现象：** 浅色的 `--surface-solid` 与 `--surface-card` 同为 `#faf9f5`，选中底色和面板亮度只差 1。
- **修法：** 新增 `--selection-fill`，浅色 `color-mix(in srgb, var(--text-primary) 8%, var(--surface-panel))`，深色 `#26282c`；`.vx-selection__mark` 改用它。高对比和强制颜色规则不变。

### C4 光标点环压在透镜文字上并晃动

- **修法：**
  1. 指针位于 `[data-visual-owner="lens"]` 内时，轨道点在 120ms 内淡到 0，收敛后停帧；离开时淡回。键盘焦点分支不受影响。
  2. `MOTION.cursor` 改为 `{ stiffness: 320, damping: 34, staggerSeconds: .04 }`，约 300ms 收敛、无超调。

## D 组：动效与界面打磨（应修）

### D1 退场曲线

- **现象：** 退场用 ease-out，80ms 的退场第一帧后就几乎看不见了。
- **修法：** `MOTION.easeExit = [.4, 0, 1, 1]`，`--ease-exit: cubic-bezier(.4, 0, 1, 1)`，用于页面、Toast、下拉、`.vx-dialog` 及 `::backdrop` 的退场。

### D2 Toast

- **现象：** 宿主切换时瞬移，替换消息时只是原地换字。
- **修法：** 继续按宿主 portal，不要改成 popover。宿主变化时 key 改为宿主标识加 `toast.id` 并播放入场；替换消息用 `key={toast.id}`，配合 `mode="popLayout"`。

### D3 创建实例弹窗

- **现象：** 选“原版”时中间空出约 110px，弹窗顶部几乎贴到窗口。
- **修法：** `create-instance.css:3` 的最小高度取两个页签中较小的实测值；loader 槽改为 `grid-template-rows: 0fr → 1fr` 的 180ms 展开，减少动态下直接切换。

### D4 游戏库工具栏

- **修法：** 控件统一 38px 高：在游戏库工具栏容器（按实际类名）下写 `:is(.vx-field, .vx-select-trigger, .vx-button) { block-size: 38px }`。视图切换外框 38px（`padding: 2px`，内部按钮 32px）。圆角统一为 `var(--radius-md)` 或全部药丸形，二选一。

### D5 详情头身份块

- **修法：** 详情头里的身份块加 `--surface-card` 底板、`--hairline` 描边、`--radius-sm` 圆角，`plane` 不透明度从 0.35 提到 0.7。卡片里不变。

### D6 透镜液态轮廓闪断

- **现象：** 透镜每次尺寸变化都会清掉 clip-path 和编码缓存，切换导航时有 1 到几帧没有液态轮廓。
- **修法：** `GlassSystem.tsx:320-325` 拆成两个 effect：依赖 `[image, shape]` 的不做 cleanup，只在缺值时 reset；另一个只在卸载时 reset。尺寸变化后先同步应用一次 `curvatureMapImage(liveShape)`，再交给异步编码器。

### D7 光标的全局监听

- **现象：** 光标的 MutationObserver 监听整棵文档的 style 和 class，动画期间每帧多一次强制布局。
- **修法：** `cursor.ts:546-556` 只观察 `documentElement` 自身的主题和档位属性；目标及其祖先另建观察器，只看 `hidden`、`disabled`、`inert`、`aria-hidden`、`aria-disabled`、`open`。

### D8 无 GPU 计时扩展时不降档

- **原因：** 没有计时扩展时，fence 跳帧会掩盖 GPU 过载，自适应降档不触发。
- **修法：** 记录上次提交时间和连续跳帧数，提交成功时以真实间隔采样。补单测：fence 连续 `TIMEOUT_EXPIRED` 时会降档。

## E 组：测试与文档卫生（应修）

1. **一项对比度断言从不执行：** `world-acceptance.spec.ts:15` 的预览胶囊断言被设为 optional，而默认测试数据始终有在线账户，所以从不运行。新增 `noAccount: true` 的一组（深浅主题、1280 和 1050），断言不再设为 optional；在线账户那组断言该元素不存在。
2. **生产代码判断测试环境：** 删除 `motion.ts:3` 读取 `process.env.VITEST` 的分支，改在 vitest 的 setup 中用 `MotionConfig` 把时长设为 0；`motion.test.ts` 断言真实时长（入场 0.18、退场 0.08、身份块弹簧 380/36）。
3. **node 测试不在 `npm test` 里：** `package.json` 加 `"test:node": "node --test tests/unit/*.test.mjs"`，`"test"` 改为同时运行两者。
4. **漏写的测试变更：** 在 0.6.0 报告中补列，包括光标半径 12→18、`liveOptics` 的 `toDataURL` 调用次数 2→1、`worldDirector` 的 eye 期望值、被替换的 `WorldScene` 回退值用例；并补一条用例覆盖 `WorldScene.tsx:55` 的初始回退 `[.62, -.66]`。
5. **静态档死代码：** 删除 `WorldScene.tsx:168` 注定返回 false 的即时完成查询，在注释中说明静态档的 settled 不可观测。
6. **计时常量：** 收进 `MOTION`，包括 Toast 停留 5000ms 和错误停留 11000ms、光标半径。
7. **系数对照：** 修复报告列出世界着色器系数的最终值与转场方案 4.3 节的对照，并把 4.2、4.3 节的修订写回转场方案。

## 不做

- 不改首页构图，不改默认强调色，不改世界背景架构。
- 不把“减少透明”从 fade 档拆出来，现行为已写入 0.5.1 报告。
- 不对全部 CSS 做 codemod。
- 不改版本号，除非用户要求。

## 补充验收

- 补抓转场方案中缺失的两条采集：抽屉关闭（要先真正打开项目详情，而不是点“安装”）、游戏库网格与列表切换（`.vx-library` 选不到元素，要改用实际的工具栏选择器）。
